# Deutsch lernen

Personal German learning progress tracker — replaces a Google Doc that was getting unwieldy to keep updating.

- [`entry.md`](./entry.md) — the running journey log: level, topics practiced, recurring difficulties, and what to focus on next.
- [`vocabulary.md`](./vocabulary.md) — vocabulary drilled so far, with a 0–5 familiarity score per word and grammar notes attached to specific items.

Current level: A2/B1.
