# CLAUDE

General-purpose repository for things Gonçalo tracks with Claude's help. Organized as one subfolder per project/topic rather than a separate repo each time.

## Structure

- `deutsch-lernen/` — German learning progress: vocabulary tracker (`vocabulary.md`) with familiarity scores, and a journey log (`entry.md`) covering level, topics practiced, recurring difficulties, and what to focus on next.

## Conventions

- Each subfolder is self-contained and can have its own README or notes file.
- When Claude is asked to update a tracked file here, it should read the existing file first and edit in place rather than replacing it wholesale, so history and phrasing stay consistent.
